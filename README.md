# Transcendencies · Transcendencies Vault — карточка для Discord

Личная карточка в стиле R34 Vault (**интерфейс 1-в-1 по эталону**: токены
выцелены из сохранённого CSS), контент — профиль: ник **Transcendencies**,
юз **@cheap.slut**, описание, статистика (1 post / 0 comments), один пост
«18+» (уже открыт — без blur и гейта) и вкладка History с рандомными треками
Sematari (обложки клипов с YouTube).

Назначение: ссылка в **профиле Discord** — по ней открывается карточка,
а OGP-теги рисуют Discord'у превью-карточку.

Один HTML-файл, чистый HTML/CSS/JS, без фреймворков и бэкенда.
Все данные — в блоке **`БЛОК 1 · ДАННЫЕ БОРДЫ`** внизу `index.html`.

## Что менять (всё в БЛОКЕ 1)

### Профиль (лицо карточки)
```js
const PROFILE = {
  user: "Transcendencies",   // ник
  handle: "@cheap.slut",     // юз под ником
  avatar: "https://unavatar.io/discord/<ТВОЙ_ID>?fallback=false", // ← ава, 3 способа — ниже
  bio: "Несерьёзная карточка для Discord. …",  // ← ОПИСАНИЕ (текст под ником) правится здесь
  since: "2014",             // "в Vault с …"
};
```

### Аватар: 3 способа (вся настройка = одна строка `PROFILE.avatar`)

Как узнать свой Discord ID (нужен для авто-вариантов):
Discord → Настройки → Дополнительно → **Режим разработчика ВКЛ** →
ПКМ по своему нику в любом чате → **Копировать ID** (получишь число).

**Способ 1 — авто (уже подключён в коде).** Вставь свой ID в ссылку
`https://unavatar.io/discord/<ТВОЙ_ID>?fallback=false`.
Дальше ава сама подхватывает твою аву с Discord: сменил в Discord —
на следующем открытии карточки уже новая, ничего руками не правишь.
Нюанс: unavatar.io — сторонний бесплатный сервис; если он ляжет —
покажется заглушка с «T» (сайт не сломается).

**Способ 2 — полный авто (без сторонников в рантайме).** Скрипт
`avatar-sync.yml` (GitHub Actions, уже в репозитории): каждые 6 часов
сам скачивает твою текущую аву и коммитит в репо как `avatar.png`.
Для включения: в скрипте вставь `DISCORD_ID`, в `PROFILE.avatar`
напиши `"avatar.png"`. Ава всегда свежая, сайт ни от чего не зависит.

**Способ 3 — руками (без всяких сервисов).** `discord.com` в браузере →
F12 → **Network** → фильтр `avatars` → F5 → скопировать
`cdn.discordapp.com/avatars/<id>/<hash>.png` → вставить в `PROFILE.avatar`.
Сменил аву в Discord → hash в ссылке поменяется → взять новую ссылку
(одна строка в коде).

Во всех вариантах: если ссылка «умрёт» — по onerror покажется заглушка
с инициалом, карточка не сломается.

### Треки (вкладка History)
`TRACKS[]` — рандомные треки Sematari с обложками клипов с YouTube
(`i.ytimg.com`). Строка = YouTube-карточка: слева обложка 16:9 с бейджем
длительности, справа — название, «просмотры · время», канал, описание.
Клик по строке открывает видео в новой вкладке.

```js
{ title: "SEMATARY - WENDIGO [OFFICIAL VIDEO]",
  video: "3:34", views: "3.6M", when: "2 years ago",
  desc: "PRODUCED WRITTEN & RECORDED BY SEMATARI GRAVE MAN. …",
  img: "https://i.ytimg.com/vi/<video_id>/hqdefault.jpg",  // обложка
  src: "https://www.youtube.com/watch?v=<video_id>" }      // ссылка
```

Добавить трек: найти видео на YouTube, взять video ID из URL (`watch?v=…`) —
он же идёт в `img` (обложка) и в `src` (ссылка).

Вкладка Playlists сейчас пуста (`PLAYLISTS = []` — по запросу). Включить
обратно — добавить объекты `{ name, items, likes, comments, members }`.

### Посты и теги — основной рабочий цикл
Сценарий «упоротая картинка + короткие фразы»: кидаешь объект в `POSTS[]`,
в `img` — картинку, в `tags` — просто строки с фразами:

```js
{
  id: 1009,
  title: "Упоротая картинка №1",
  img: "posts/uporota.jpg",      // или "https://…", или null = заглушка
  video: null,
  rating: 12,
  views: 340,
  published: "today",
  date: "Nov 9, 2026, 3:23:00 PM",
  source: "t.me/vse_chasty/1",
  tags: ["это не баг это фича", "смотрел 3 раза", "нельзя объяснить"],  // ← и всё
  comments: [],
}
```

Текущий пост — `nsfw: false`, т.е. уже открыт: без blur, без плашки 18+, без
гейта «да/нет»; теги сразу видны на большой карточке Bookmarks.
Хочешь, чтобы пост выглядел как NSFW (blur + плашка 18+ + гейт «да/нет», а внутри
нормальная картинка) — поставь `nsfw: true`. Такой пост автоматически становится
большой плиткой в витрине Bookmarks.

Теги:
- `"короткая фраза"` — синий тег (по умолчанию);
- `"фраза=pink"` — цветной: `pink` / `green` / `red` / `teal` / `gray`.

**Быстро добавить/перекрасить тег:** в `POSTS[0]` доращиваешь массив
`tags` одной строкой — `tags: ["femdom", "новое слово=pink"]` — и всё:
счётчики пересчитаются, тег появится на карточке, на странице поста
и со своей страницей.

Категории: `copyright · character · artist · general · meta · system`
(цвета — в `:root`). Механика как на эталоне:
- первые 10 тегов, дальше чип «Show more (+N)»;
- при наведении на тег — подсказка с числом постов по нему;
- **клик по тегу = отдельная страница тега** (`#tag/<имя>`): заголовок с цветным
  чипом и сетка постов по этому тегу.

## Деплой + Discord (главный путь)

1. **Деплой** (любой вариант):
   - **GitHub Pages**: загрузи в репо `index.html`, `preview.png`, `favicon.png`;
     Settings → Pages → Deploy from branch → `main`, `/ (root)`.
     Ссылка: `https://<логин>.github.io/<репозиторий>`
   - **Vercel**: Add New → Project → импортировать репо → Framework «Other» → Deploy.
     Ссылка: `https://<имя>.vercel.app`
   - Важно: `preview.png` должен открываться по полной ссылке вида
     `https://твой-домен/preview.png` (Discord ходит за картинкой напрямую).
2. **Discord**: Настройки → Профиль → блок ссылок (About Me / Links) → вставь
   свой URL. В профиле ссылка будет кликабельной, а в чатах, где её перешлют,
   Discord отрисует карточку из OGP (заголовок, описание, preview.png).

## А может, форкнуть готовый опенсорс?

Готовых **статических** шаблонов бооров «форкни в один клик» практически нет —
все зрелые опенсорсные борды это **PHP + база данных**:

| Проект | Что это | Когда брать |
|---|---|---|
| [MyTinyBoard](https://github.com/mrbobbytables/MyTinyBoard) | booru-стиль: теги, поиск, тёмная тема | реальная борда с кастомом |
| [Shimmie2](https://github.com/shish/shimmie2) | классическая тег-борда | простая надёжная структура |
| [TinyIB](https://codeberg.org/tslocum/TinyIB) / [Tinyboard](https://github.com/Circlepuller/Tinyboard) / [fukuro](https://github.com/twiforce/fukuro) | лёгкие 4chan-подобные (есть режим без БД) | движок анонимных тредов |
| [LibreBooru](https://github.com/5ynchrogazer/LibreBooru) | лёгкий booru (PHP+MySQL) | danbooru-подобный поиск |

Это PHP-приложения: на GitHub Pages/Vercel не встают (нужен VPS с PHP + MySQL
или Docker). Для визитки с фиксированным контентом статический вариант выше:
одна страница, ноль бэкенда, деплой за 2 минуты.
